# 智谱AI开放文档

> Z智谱开放平台开发者文档中心

## Docs

- [对话历史](https://docs.bigmodel.cn/api-reference/agent-api/对话历史.md): 查询智能体对话历史，现仅支持 `slides_glm_agent` 智能体
- [异步结果](https://docs.bigmodel.cn/api-reference/agent-api/异步结果.md): 查询智能体异步任务的处理结果和状态。
- [智能体对话](https://docs.bigmodel.cn/api-reference/agent-api/智能体对话.md): 与智能体进行对话交互。支持同步和流式调用，提供智能体的专业能力。见 [智能体文档](/cn/guide/agents/translation)
- [问答 Agent 对话（流式）](https://docs.bigmodel.cn/api-reference/agent-api/问答-agent-对话（流式）.md): 基于 ReAct（Reasoning + Acting）推理引擎的流式对话接口。LLM 会根据用户问题自主决定是否调用工具（知识检索、查询重写等），并通过 SSE 实时推送思考过程、工具调用和最终回答。
- [助手会话列表](https://docs.bigmodel.cn/api-reference/助理-api/助手会话列表.md): 查询指定智能体助手的会话列表，支持分页查询。
- [助手列表](https://docs.bigmodel.cn/api-reference/助理-api/助手列表.md): 查询指定的智能体助手列表信息，包括智能体助手的详细配置、工具和元数据。
- [助手对话](https://docs.bigmodel.cn/api-reference/助理-api/助手对话.md): 与`AI`助手进行对话，支持流式和同步模式。
- [OCR 服务](https://docs.bigmodel.cn/api-reference/工具-api/ocr-服务.md): 上传图片文件，使用指定工具类型进行 OCR（光学字符识别），支持手写体、文字等识别模式，见 [OCR 服务](/cn/guide/tools/zhipu-ocr)
- [内容安全](https://docs.bigmodel.cn/api-reference/工具-api/内容安全.md): 可对文本、图片、音频、视频格式类型的内容进行检测，精准识别涉黄、涉暴、违法违规等风险内容，并输出结构化审核结果（包括内容类型、风险类型及具体风险内容片段），快速定位和处理违规信息。
- [文件解析](https://docs.bigmodel.cn/api-reference/工具-api/文件解析.md): 创建文件解析任务，支持多种文件格式和解析工具。见 [文件解析服务](/cn/guide/tools/file-parser)
- [文件解析(同步)](https://docs.bigmodel.cn/api-reference/工具-api/文件解析同步.md): 创建文件解析任务，支持多种文件格式和解析工具。见 [文件解析服务](/cn/guide/tools/file-parser)
- [网络搜索](https://docs.bigmodel.cn/api-reference/工具-api/网络搜索.md): `Web Search API` 是一个专给大模型用的搜索引擎，在传统搜索引擎网页读取、排序的能力基础上，增强了意图识别能力，返回更适合大模型处理的结果（网页标题、`URL`、摘要、名称、图标等）。支持意图增强检索、结构化输出和多引擎支持。见 [网络搜索服务](/cn/guide/tools/web-search)
- [网页阅读](https://docs.bigmodel.cn/api-reference/工具-api/网页阅读.md): 读取并解析指定 `URL` 的网页内容，可选择返回格式、支持控制缓存、图片保留与摘要选项等。
- [解析结果](https://docs.bigmodel.cn/api-reference/工具-api/解析结果.md): 异步获取文件解析任务的结果，支持返回纯文本或下载链接格式。见 [文件解析服务](/cn/guide/tools/file-parser)
- [列出批处理任务](https://docs.bigmodel.cn/api-reference/批处理-api/列出批处理任务.md): 获取批量处理任务列表，支持分页。见 [批量服务](/cn/guide/tools/batch)
- [创建批处理任务](https://docs.bigmodel.cn/api-reference/批处理-api/创建批处理任务.md): 创建一个新的批量处理任务。见 [批量服务](/cn/guide/tools/batch)
- [取消批处理任务](https://docs.bigmodel.cn/api-reference/批处理-api/取消批处理任务.md): 根据批处理任务`ID`取消正在运行的批量处理任务。见 [批量服务](/cn/guide/tools/batch)
- [检索批处理任务](https://docs.bigmodel.cn/api-reference/批处理-api/检索批处理任务.md): 根据批处理任务`ID`获取批量处理任务详情。见 [批量服务](/cn/guide/tools/batch)
- [上传文件](https://docs.bigmodel.cn/api-reference/文件-api/上传文件.md): 上传用于 `Batch 任务`、`智能体` 等功能的文件。注意 `Try it` 功能仅支持小文件上传，实际支持的文件大小请参见下文 `purpose` 相关说明。
- [删除文件](https://docs.bigmodel.cn/api-reference/文件-api/删除文件.md): 永久删除指定文件及其所有关联数据。
- [文件内容](https://docs.bigmodel.cn/api-reference/文件-api/文件内容.md): 获取文件内容。只支持 `batch` 文件类型。
- [文件列表](https://docs.bigmodel.cn/api-reference/文件-api/文件列表.md): 获取已上传文件的分页列表，支持按用途和排序过滤。
- [创建新会话](https://docs.bigmodel.cn/api-reference/智能体-api（旧）/创建新会话.md): 为指定智能体（应用）创建新会话，返回会话`ID`。
- [推理接口](https://docs.bigmodel.cn/api-reference/智能体-api（旧）/推理接口.md): 对话型或文本型应用推理接口，支持同步和流式`SSE`调用。
- [推荐问题接口](https://docs.bigmodel.cn/api-reference/智能体-api（旧）/推荐问题接口.md): 获取推荐问题列表。
- [文件上传](https://docs.bigmodel.cn/api-reference/智能体-api（旧）/文件上传.md): 上传文件到智能体（应用），同步返回上传结果。需通过文件解析状态接口获取解析结果。
- [知识库切片引用位置信息](https://docs.bigmodel.cn/api-reference/智能体-api（旧）/知识库切片引用位置信息.md): 获取知识库切片引用的位置信息。
- [获取文件解析状态](https://docs.bigmodel.cn/api-reference/智能体-api（旧）/获取文件解析状态.md): 获取指定文件的解析状态。
- [获取智能体输入参数](https://docs.bigmodel.cn/api-reference/智能体-api（旧）/获取智能体输入参数.md): 获取指定智能体应用的输入参数列表。
- [删除音色](https://docs.bigmodel.cn/api-reference/模型-api/删除音色.md): 删除指定的音色。
- [图像生成](https://docs.bigmodel.cn/api-reference/模型-api/图像生成.md): 使用 [GLM-Image](/cn/guide/models/image-generation/glm-image) 等系列模型从文本提示生成高质量图像。通过对用户文字描述快速、精准的理解，让 `AI` 的图像表达更加精确和个性化。
- [图像生成(异步)](https://docs.bigmodel.cn/api-reference/模型-api/图像生成异步.md): 使用 [GLM-Image](/cn/guide/models/image-generation/glm-image) 系列模型从文本提示生成高质量图像。通过对用户文字描述快速、精准的理解，让 `AI` 的图像表达更加精确和个性化。仅支持 `GLM-Image` 模型。
- [对话补全](https://docs.bigmodel.cn/api-reference/模型-api/对话补全.md): 和 [指定模型](/cn/guide/start/model-overview) 对话，模型根据请求给出响应。支持多种模型，支持多模态（文本、图片、音频、视频、文件），流式和非流式输出，可配置采样，温度，最大令牌数，工具调用等。
- [对话补全(异步)](https://docs.bigmodel.cn/api-reference/模型-api/对话补全异步.md): 和 [指定模型](/cn/guide/start/model-overview) 对话，通过查询异步结果获取模型响应。支持多种模型，支持多模态（文本、图片、音频、视频、文件），可配置采样，温度，最大令牌数，工具调用等。注意此为异步接口，通过 [查询异步结果](/api-reference/%E6%A8%A1%E5%9E%8B-api/%E6%9F%A5%E8%AF%A2%E5%BC%82%E6%AD%A5%E7%BB%93%E6%9E%9C) 获取生成结果。
- [文本分词器](https://docs.bigmodel.cn/api-reference/模型-api/文本分词器.md): `Tokenizer` 用于将文本切分为模型可识别的 `token` 并计算数量。它接收用户输入的文本，通过模型进行分词处理，最终返回对应的 `token` 数量。适用于文本长度评估、模型输入预估、对话上下文截断、费用计算等。
- [文本嵌入](https://docs.bigmodel.cn/api-reference/模型-api/文本嵌入.md): 使用 [GLM Embedding](/cn/guide/models/embedding/embedding-3) 系列模型将文本转换为高维向量表示，用于语义相似性和搜索。
- [文本转语音](https://docs.bigmodel.cn/api-reference/模型-api/文本转语音.md): 使用 `GLM-TTS` 将文本转换为自然语音，支持多种声音、情感控制和语调调整。
- [文本重排序](https://docs.bigmodel.cn/api-reference/模型-api/文本重排序.md): `Rerank` 用于文本重排序，通过接收用户的查询文本及候选文本列表，使用模型计算候选文本与查询文本的相关性得分并返回分数。适用于智能问答、信息检索等场景。
- [文档解析](https://docs.bigmodel.cn/api-reference/模型-api/文档解析.md): 使用 [GLM-OCR](/cn/guide/models/vlm/glm-ocr) 模型解析文档和图片的布局并提取文本内容。支持图片和`PDF`文档的`OCR`识别，返回详细的布局信息和可视化结果。
- [查询异步结果](https://docs.bigmodel.cn/api-reference/模型-api/查询异步结果.md): 查询对话补全和视频生成异步请求的处理结果和状态。
- [视频生成(异步)](https://docs.bigmodel.cn/api-reference/模型-api/视频生成异步.md): 通过调用 [视频模型](/cn/guide/models/video-generation/cogvideox-3) 能力生成视频内容。支持多种视频生成方式，包括文本转视频、图像转视频等。注意此为异步接口，通过 [查询异步结果](/api-reference/%E6%A8%A1%E5%9E%8B-api/%E6%9F%A5%E8%AF%A2%E5%BC%82%E6%AD%A5%E7%BB%93%E6%9E%9C) 获取生成视频结果。
- [语音转文本](https://docs.bigmodel.cn/api-reference/模型-api/语音转文本.md): 使用 [GLM-ASR-2512](/cn/guide/models/sound-and-video/glm-asr-2512) 模型将音频文件转录为文本，支持多语言和实时流式转录。
- [音色列表](https://docs.bigmodel.cn/api-reference/模型-api/音色列表.md): 获取音色列表，支持按音色名称模糊搜索、按音色类型过滤。
- [音色复刻](https://docs.bigmodel.cn/api-reference/模型-api/音色复刻.md): 使用音色复刻技术，基于示例音频生成指定音色、文本内容的语音合成。
- [上传URL文档](https://docs.bigmodel.cn/api-reference/知识库-api/上传url文档.md): 上传`URL`类型的文档或网页作为内容填充知识库。
- [上传文件文档](https://docs.bigmodel.cn/api-reference/知识库-api/上传文件文档.md): 向指定知识库上传文件类型文档，支持多种切片方式和回调。
- [全模态知识库检索](https://docs.bigmodel.cn/api-reference/知识库-api/全模态知识库检索.md): 用于检索全模态知识库，支持文本、图片、视频等多模态输入检索，支持向量检索、关键词检索、混合检索，支持查询重写、重排、QA干预等高级功能。
- [创建知识库](https://docs.bigmodel.cn/api-reference/知识库-api/创建知识库.md): 用于创建个人知识库，支持绑定向量化模型、设置名称、描述、背景色和图标。
- [删除文档](https://docs.bigmodel.cn/api-reference/知识库-api/删除文档.md): 根据文档`ID`删除文档。
- [删除知识库](https://docs.bigmodel.cn/api-reference/知识库-api/删除知识库.md): 根据知识库`ID`删除个人知识库。
- [文档列表](https://docs.bigmodel.cn/api-reference/知识库-api/文档列表.md): 获取指定知识库下的文档列表。
- [文档详情](https://docs.bigmodel.cn/api-reference/知识库-api/文档详情.md): 根据文档`ID`获取文档详情。
- [知识库使用量](https://docs.bigmodel.cn/api-reference/知识库-api/知识库使用量.md): 获取个人知识库的使用量详情，包括字数和字节数。
- [知识库列表](https://docs.bigmodel.cn/api-reference/知识库-api/知识库列表.md): 获取个人知识库列表，支持分页。
- [知识库检索](https://docs.bigmodel.cn/api-reference/知识库-api/知识库检索.md): 用于检索个人知识库，支持向量检索、关键词检索、混合检索，支持自定义重排模型。
- [知识库详情](https://docs.bigmodel.cn/api-reference/知识库-api/知识库详情.md): 根据知识库`ID`获取个人知识库详情。
- [编辑知识库](https://docs.bigmodel.cn/api-reference/知识库-api/编辑知识库.md): 用于编辑已经创建好的个人知识库，仅传入要修改的字段。
- [解析文档图片](https://docs.bigmodel.cn/api-reference/知识库-api/解析文档图片.md): 用于获取文件下解析到的图片序号和图片链接映射关系。
- [重新向量化](https://docs.bigmodel.cn/api-reference/知识库-api/重新向量化.md): 用于重新向量化文档（重试等操作）。同步返回成功表示调用成功，向量化完成后调用`callback_url`进行通知，也可调用知识详情接口获取结果。多用于`url`知识场景。
